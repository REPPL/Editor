# Editor documentation

Editor is a lightweight Markdown editor for notes and presentations. You keep a
document as a folder of Markdown files; Editor gives you an editing surface with
Emacs keys, a deck you can project, and one press that publishes both the talk
and the article to a link you can send.

These pages follow [Diátaxis](https://diataxis.fr): each one is exactly one
kind of thing, so you always know which to open.

## Tutorial

Learning-oriented. Start here if you have not used Editor before.

- [Your first talk](tutorial-your-first-talk.md) — open one of the bundled
  examples, edit it with a few chords, insert a divider, project it, and dry-run
  a publish. About twenty minutes.

- [Edit prose with Emacs commands](how-to-edit-prose-with-emacs-commands.md) —
  reflow a paragraph, move by sentence, complete a word from the document, and
  run any command by name from `M-x`.
- [Move through the outline](how-to-move-through-the-outline.md) — move,
  fold, promote, demote and move a heading, narrow to a section, switch
  chapter by name, and find every line that holds a word.
- [Drop images, videos and files](how-to-drop-images-videos-and-files.md) —
  what Editor does with each kind of dropped file, what it takes out of a
  picture, and what to do when a drop is refused.

  — set up the git repository and the static host that publishing pushes to.
- [Export a folder you can carry](how-to-export-a-folder.md) — write the deck
  or the article as a folder that opens from disk, and look at what a publish
  would push before pushing it.
- [Preview and read the article](how-to-preview-and-read-the-article.md) —
  open the article preview, the contents list, margin notes, and the video
  rule, at every width a reader might open the page.
- [Cite from a bibliography file](how-to-cite-from-a-bibliography-file.md) —
  name a `.bib` file, complete and hover a key as you type it, and see what
  an unresolved key and a generated reference list look like in each
  rendering.
- [Hide things in the text](how-to-hide-things-in-the-text.md) — a once-only
  opening quotation, an easter egg's marker and its block, and what a
  mismatched marker or block looks like in the sidebar.
