# Opinionated conventions

The `OPINIONS` rule domain names each of these in one line and points here for
the rest. One file per convention, so a prompt that matches the domain costs a
line and reading the whole argument is a deliberate act.

Each file says what the convention is, why it earns its keep, what it costs,
and how to tell it is being followed. A convention with no cost stated is a
slogan; a convention with no test stated cannot be held to.

| Principle | In one line |
|---|---|
| [Prefer SOTA, adversary-filtered](prefer-sota.md) | The credible state of the art is the presumptive pick, and it still has to survive a challenge for fit here |
| [One canonical primitive](one-canonical-primitive.md) | Find the canonical home and extend it; never add a third copy |
| [Evaluator outside the loop](evaluator-outside-the-loop.md) | Whoever reviews an option did not propose it |
| [Verifier selects, gates decide](verifier-selects-gates-decide.md) | A verdict is a proposal; adoption is the maintainer's |
| [Loud staging](loud-staging.md) | A stage that no-ops or degrades says so; never a false green |
| [Script-first MVP](script-first-mvp.md) | Earn each tool rung; the smallest documented protocol comes first |
| [Memory graduates to the record](memory-graduates-to-record.md) | A correction any agent should receive belongs in the committed record |
