# Identity

## Identity (canonical)

The single recorded home for how this project names itself. Every public
surface — the README strapline, the package or plugin manifest description,
the conventions file's opening — renders from these three lines; a surface
that says something else is drift, fixed by re-rendering from here or by
deliberately changing this block.

- **Title:** Editor
- **Tagline:** A lightweight Markdown editor for notes and presentations.
- **Pitch:** Editor is a small, fast Markdown editor for people who write notes and build presentations from the same plain-text files. It stays out of the way: no proprietary format, no cloud account, and nothing between you and the file on disk.
